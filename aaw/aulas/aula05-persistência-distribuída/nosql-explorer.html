Banco de Dados Orientado a Documentos
Dados são armazenados como documentos JSON/BSON. Não há schema fixo — cada documento pode ter campos diferentes. Ideal para dados hierárquicos e variáveis.

BSON: extensão binária do JSON com tipos extras (Date, ObjectId, etc.)
Banco de Dados Chave-Valor
Cada registro é um par chave → valor. Extremamente rápido (dados em memória). Suporta múltiplos tipos de valor: strings, listas, hashes, sets e sorted sets.

Conceitos-chave
In-memory: todos os dados ficam na RAM → latência sub-milissegundo
TTL (Time To Live): chaves podem expirar automaticamente
Tipos: String, List, Hash, Set, Sorted Set, Stream
Uso comum: cache de sessão, filas de mensagens, ranking em tempo real
Banco de Dados Colunar (Column-Family)
Organiza dados em famílias de colunas. Cada linha tem uma chave e pode ter colunas diferentes. Distribuído e altamente escalável. Ideal para séries temporais e analytics.

Conceitos-chave
Partition Key: determina em qual nó do cluster os dados ficam
Clustering Column: ordena os dados dentro de uma partição
Sparse Columns: linhas diferentes podem ter colunas diferentes (sem NULL = sem espaço)
Uso comum: IoT, séries temporais, logs, métricas de alta escala
Banco de Dados de Grafos
Dados são nós (entidades) conectados por arestas (relacionamentos). Cada nó e relação pode ter propriedades. Ideal para redes sociais, recomendações e detecção de fraudes.
