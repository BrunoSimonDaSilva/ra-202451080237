# Aulas — Arquitetura de Aplicações Web

Material e exercícios práticos de cada aula, um subdiretório por aula.

| Pasta | Tema |
|---|---|
| `aula02-rest/` | APIs REST com ASP.NET Core |
| `aula09-rbac/` | Autorização RBAC, ABAC e PBAC |
| `aula10-documentação/` | Documentação de APIs com OpenAPI/Swagger |
| `aula11-testes-e-qualidade/` | Testes unitários e de integração |
| `aula12-revisão/` | Revisão das aulas 01 a 11 |
